# PluralPal
A companion app that runs both on web and locally, for plural people to catalogue their alters, maintain conversation amongst themselves, and show others who is fronting and how they're feeling, all from the comfort of your browser!

# How to run
First of all, make sure you have PHP and MariaDB set up appropiately on your infrastructure. Next, use the `DB_Create.sql` script to create all the neccessary SQL tables and information.

After this, edit the information in `db.php` to suit your setup.
